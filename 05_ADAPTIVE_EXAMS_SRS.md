# Claude Prompt 05 — ADAPTIVE LEARNING + WEEKLY EXAMS

Next.js және Supabase базасына mastery scoring, error journal, spaced repetition (SRS) және апталық емтихан енгіз.

Талаптар:
- CEFR level — тек completion count емес, тақырыптық нақты дәлел бойынша.
- Әр lesson objective үшін score + confidence сақталсын.
- Бір ғана төмен нәтиже деңгей түсірмеуі керек; кемі бірнеше әрекетті қолдан.
- Vocabulary карточкалары үшін spaced repetition (қажет болса FSRS принциптерін зерттеу, лицензиясын тексеру).
- Weekly exam categories: Grammar, Vocabulary, Listening, Reading, Writing, Speaking; бастапқы кезеңде Listening/Speaking/Writing қолжетімсіз болса оларды шынымен тексерілген деп көрсетпе.
- Time window: жексенбі 20:00–21:00; flexible reschedule мүмкіндігі.
- Test question answer keys server-side; жауапты тест біткенге дейін ашпа.
- Summary screen: strengths, weaknesses, mistakes, next week plan.
- Tests: unlock/prerequisites, scoring, retake, edge cases, privacy.

Іске асыру алдында қысқа implementation plan көрсет; сосын жазып, тесттеп, осы кезең соңында тоқта.
