# LinguaPath AI — Claude арқылы бірге жасайтын жоба

**Міндет:** ағылшынды Beginner деңгейінен бастап B2-ге дейін жүйелі оқытатын, қазақша/қытайша/ағылшынша түсіндіретін жеке платформа. Дәл қазір тек алғашқы WORKING PROTOTYPE (демо) дайын.

## 1. Папкадағы материалдар

- `website/` — браузерде ашылатын бастапқы сайт: A0–A1 үлгі сабақтары, тест, сөздік ойыны, прогресс, кесте, демо Mira.
- `claude-prompts/` — Claude-қа **ретімен** берілетін 8 промпт.
- `docs/` — толық жоба талаптары, контент сілтемелері, сабақ жүйесі, деректер құрылымы, қауіпсіздік және жұмыс жоспары.
- `assets/` — кейін өз иллюстрацияларыңды, логотипті, видео/аудионы сақтайтын орын.

## 2. Ең бірінші не істеу керек?

1. Репозиторийді компьютеріңе көшір: `git clone https://github.com/aidnaiagoz-lgtm/LinguaPath-AI.git` (немесе GitHub-та **Code → Download ZIP**).
2. `website/index.html` файлын екі рет бас. Алғашқы сайт браузерде ашылады — әзірге сервердің де, ақылы AI API-ның да қажеті жоқ.
3. Сайттың «Сабақтар» бөлімінен бірінші сабақты өтіп көр; «Ойындар» мен «Апталық емтиханды» да тексер.
4. **Claude Code** (немесе Claude-тың файл тіркей алатын жобалық чаты) арқылы осы папканы аш.
5. Ең алдымен `claude-prompts/01_START_HERE.md` файлының мәтінін Claude-қа жібер.
6. Claude бірінші қадамды аяқтаған соң ғана келесі промптқа өт. Әр қадамда жасалған өзгерістерді Git commit-ке сақтау ұсынылады.

## 4. Claude арқылы жобаны қалай дамытамыз?

Бірінші қадам — дайын прототипті түсініп, сапасын арттыру. Екінші қадам — Next.js + TypeScript + Tailwind нұсқасына көшіру. Үшінші қадам — Supabase, содан кейін қауіпсіз AI API, дауыс, бейімделу, тест және IELTS.

**Әр промптты бір-бірлеп жібер.** Егер Claude бір қадамда қате шығарса, келесі кезеңге өтпей, Claude-қа қателікті түзеттіреміз. `08_DEBUG_REVIEW.md` файлын пайдалан.

## 5. Құқық, құпиялылық және шығын

- BBC, Bilibili, British Council және басқа сайттардың толық сабақтарын көшіріп орналастырма. Тек лицензиясы рұқсат беретін контент не сілтеме/рұқсат етілген embed.
- Құпия API key-ді `website/` ішіне салма. Шынайы AI келесі кезеңде тек сервер жағынан шақырылуы тиіс.
- AI қолданатын бұлтты сервис тегін болуы міндетті емес. Бюджет лимиті, quota, usage tracking қосылады.
- Дауыстық жазбаны қолданар алдында келісім және жою мүмкіндігі қажет.
