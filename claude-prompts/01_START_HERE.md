# Claude Prompt 01 — ЖОБАМЕН ТАНЫСУ + АУДИТ

Сен 10+ жыл тәжірибесі бар senior full-stack developer, learning product designer, security reviewer және QA engineer рөлдерін атқарасың. Біз `LinguaPath_AI_Claude_Project` папкасындағы жеке ағылшын үйрететін LinguaPath AI платформасын бірге дамытамыз. Барлық жауаптарың қазақша болсын (код ағылшынша болуы мүмкін). Жұмыс істеп тұрған функцияларды бұзба.

Алдымен міндетті түрде оқы:
- `README_FIRST_KK.md`
- `docs/PROJECT_REQUIREMENTS_KK.md`
- `docs/LEARNING_PROGRAM_KK.md`
- `docs/CONTENT_SOURCES_AND_LICENSES.md`
- `docs/PROJECT_ROADMAP_AND_QA.md`
- `website/index.html`, `website/styles.css`, `website/data.js`, `website/app.js`

Тапсырма:
1. Жобаның ағымдағы құрылымын түсін. Оны нөлден қайта жазба.
2. Функциялар тізімін «нақты жұмыс істейді / тек демо / жоқ» деп бөл.
3. Нақты табылған қателерді жөнде: responsive, keyboard navigation, data safety, quiz edge cases, accessibility.
4. Тест жаса/орында. Қолыңда браузер құралы болса, 375px және 1440px көріністерін тексер.
5. Өзгерістерді қысқаша жаз, файлдар бойынша көрсет, іске қосу нұсқаулығын бер.
6. **Осы қадам аяқталғанда тоқта.** Келесі кезеңге мен рұқсат бергенде ғана өт.
